To run: >> python main.py 'SEARCH QUERY'
First, put the images you want to search through in the 'input' folder. 
After search, the tool will print all entries containing your search query. 
The tool will also copy all images containing the query to the 'output' folder, so further manual search through these images will be easy.
Note: Each time you run the program, the output folder is erased. If you want to keep it, you should change its name before running the program again.
